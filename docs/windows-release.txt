SleepChord for Windows x64
=========================

Extract the entire folder to a location you can access and double-click
SleepChord.exe. Keep the supplied Microsoft runtime DLLs alongside the EXE.
SleepChord runs as a normal user without development tools.

Use a supported 64-bit Windows 10 or 11 system with an audio device and a
graphics driver that provides OpenGL. The optional Vulkan renderer needs a
compatible Vulkan driver. Windows N editions may need Microsoft's Media
Feature Pack for the Windows media components imported by the application.
Embedded sign-in and web verification use Microsoft's Edge WebView2 Evergreen
Runtime. If it is missing, get it from https://developer.microsoft.com/microsoft-edge/webview2/.

Streaming, sign-in, remote artwork and lyrics require network access. Native
playback uses embedded decoders and does not need FFmpeg, FFprobe, Python or
Node.js. Certain restricted or signed-in tracks can fall back to yt-dlp,
which SleepChord downloads from a pinned upstream release into the user profile.
SleepChord verifies its SHA-256 digest before storing it and before each run.
The fallback uses a private directory for temporary authentication files.
The existing fallback uses Node.js if available, or a supported default
JavaScript runtime found by yt-dlp. See https://github.com/yt-dlp/yt-dlp/wiki/EJS.
Discord Rich Presence needs a running Discord desktop client if enabled.

Existing settings, local library data, history, cached artwork, sign-in
profiles and logs use %APPDATA%\ytm-rs\data. Windows sign-in secrets are stored
by Windows Credential Manager, which also stores configured add-on links.
Track downloads default to the existing
Music\BitChord folder. Keep personal profiles and logs out of shared copies.

LICENSE and THIRD-PARTY-NOTICES.txt describe the bundled code and assets.
SHA256SUMS.txt can be used to check package integrity. This local build is
unsigned. For public distribution, provide the exact corresponding source
under GPLv3 and complete the reviews described in THIRD-PARTY-NOTICES.txt.
This Windows package does not use the inherited BitChord updater.
