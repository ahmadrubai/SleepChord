# SleepChord v2.0.1 for Windows x64

**Local release draft. GitHub publication is blocked.**

SleepChord 2.0.1 focuses Explore, Search, and the playback queue on music. Smart Queue, music-only radio and autoplay, library and transfer tools, Live Lyrics, and Listen Together remain part of the app. Official music videos can use audio-only playback.

- **Pure Music Experience.** Removed podcast discovery and playback. Mixed and legacy data are filtered for playback while the original saved records are preserved.
- **Security.** Verified yt-dlp downloads and cached binaries, private helper workspaces, WebView2 reputation protection, origin checks, protected settings, and bounded QuickJS. The Windows package disables the inherited updater.
- **Performance.** Removed podcast discovery requests. Retained next-track prefetch, incremental playlist loading, and virtualized long lists. Performance was not benchmarked for this draft.
- **Windows.** Native Windows x64 GUI and per-user Setup. Local startup, saved-data migration, and installer wizard navigation were checked on Windows 11 x64.

## Local installation and upgrades

Use an approved disposable Windows x64 environment. Verify the hash first. Run `SleepChord-Setup-2.0.1-x64.exe` and keep the same install directory when testing an upgrade. Close SleepChord if Setup prompts. Settings and credentials remain in the existing Windows user profile and vault. See the [installer guide](../windows-installer.md).

~~~powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\SleepChord-Setup-2.0.1-x64.exe
~~~

Compare the result with `83a7924c4128a4669e3bb76cc2167879b821e03bce139b2f95bc94240c55c2a5` and the staged `dist/installer/SHA256SUMS.txt` manifest. The installer is 11,907,541 bytes. The staged `SleepChord.exe` is 30,788,096 bytes and has SHA-256 `4e82ca4dddcdd44f4436ddf75e5a65d2bd0b7d5092192c2581c44908776327f1`. These hashes identify the current unsigned local artifacts.

## System requirements

- 64-bit Windows 10 or Windows 11, an audio output device, and an OpenGL-capable graphics driver. The optional Vulkan renderer needs a Vulkan-capable driver.
- Microsoft Edge WebView2 Evergreen Runtime for sign-in and web verification. Windows N editions may need Microsoft's Media Feature Pack. Setup includes the VC runtime DLLs.
- Internet access for streaming, sign-in, artwork and lyrics. The restricted-track fallback may need Node.js or another JavaScript runtime supported by yt-dlp. Discord Rich Presence needs the Discord desktop client when enabled.

## Known limitations

Full-length playback, live Google and Spotify sign-in and transfer, party synchronization, and clean installation and upgrade still need testing outside this sandbox. Provider metadata can be incomplete. The Feature 3.4 test run recorded 231 passing tests, 26 ignored, and three sandbox failures in registry access, Credential Manager, and legacy credential migration.
