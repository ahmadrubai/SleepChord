SleepChord Windows x64 third-party notices
=========================================

SleepChord is based on BitChord PC Continued by jackychan4891 and contributors
(https://github.com/jackychan4891/BitChord-PC-Continued), with lineage from
BitChord (https://github.com/kushagrasinghx/BitChord) and the ytm-rs backend
(https://github.com/grapedjuice/ytm-rs). The program is GPL-3.0-only.
See LICENSE. Preserve the original source headers and credits.

The Windows build embeds the Rust audio stack (rodio, CPAL, Symphonia,
rusty-opus and filmcraft-ac3), egui and its fonts, QuickJS via rquickjs,
yt-dlp/ejs 0.8.0, the application assets and the static Microsoft WebView2
loader. Symphonia's AAC decoder also credits Kostya Shishkov's NihAV project.
The app-local vcruntime DLLs, when present, are Microsoft redistributable
code shipped from Visual Studio's x64 REDIST directory. Windows, its drivers,
and the separate WebView2 Evergreen Runtime supply system components.
