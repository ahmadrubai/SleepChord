# Security policy

SleepChord 2.0.1 is a local testing build. A public support or patch commitment has yet to be established.

## Report a vulnerability privately

Use the private contact method provided by the maintainer who supplied the test build. A GitHub private vulnerability-reporting endpoint has yet to be configured. Ask the maintainer for a private channel before sending sensitive evidence. Include the affected build, Windows version, expected and observed behavior, and minimal reproduction steps. Scrub cookies, passwords, tokens, signed URLs, and profile information from attachments.

## Verification and release status

Check local installer hashes against the [release draft](docs/releases/v2.0.1.md). Respect Windows and organization controls when testing the unsigned build. The verification workflow is intended for a trusted test environment. See the [security and licensing gates](docs/github-release-preparation.md) for public distribution and the [privacy notes](docs/privacy.md) for local data handling.
